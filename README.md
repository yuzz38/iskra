# Искра — лендинг персональных журналов на заказ

Одностраничный сайт для @iskra.journal: персональные журналы о самых любимых людях (PDF 3 500 ₽ / печать в подарочной упаковке 4 500 ₽, доставка по России).

## Структура

```
index.html            — страница (10 блоков + футер), микроразметка Schema.org (Organization, Service, Offer, FAQPage)
css/style.css         — стили, адаптив 1440 → 320 px
js/main.js            — меню-бургер, конструктор крышки, полка тем, табы работ, лайтбокс, слайдер отзывов, видео
assets/img/           — изображения WebP (480/960) + JPG-фолбэк, иконки, og-image.jpg (1200×630)
assets/video/         — два ролика H.264 540p без звука (~1 МБ каждый)
favicon.svg / .ico    — иконки
robots.txt            — индексация (в т.ч. AI-ботами)
sitemap.xml           — карта сайта с изображениями
llms.txt              — краткое описание бизнеса для нейросетевого поиска (GEO)
site.webmanifest      — PWA-манифест
.htaccess             — gzip и кеширование для Apache
```

## Блоки

1. Первый экран с конструктором: посетитель вписывает имя и выбирает повод — надпись на крышке с оливковым сердцем меняется, а текст заявки копируется для директа.
2. Поводы + плашка ко Дню матери (29 ноября).
3. Темы — «полка» из корешков (happy birthday, love story, friend story, travel story, про питомца).
4. Работы — табы с разворотами реальных журналов и лайтбоксом.
5. Видео — два ролика, проигрываются только в зоне видимости.
6. Из чего собирается журнал — рубрики.
7. Как рождается журнал — 6 шагов листами, которые ложатся стопкой при прокрутке.
8. Форматы и цены.
9. Отзывы — слайдер (свайп, стрелки, точки, клавиатура).
10. Вопросы + финальный призыв.

Карты нет: у «Искры» нет физического адреса, работа онлайн с доставкой по России.

## Перед публикацией

- Домен `https://iskra-journal.ru/` указан условно — замените во всех файлах (index.html, robots.txt, sitemap.xml, llms.txt) на реальный.
- **Отзывы в блоке 9 — шаблон.** Замените их на настоящие отзывы клиентов (текст, имя, тема журнала) до публикации.
- Все кнопки «Заказать» ведут в директ `https://ig.me/m/iskra.journal`; текст заявки копируется в буфер обмена (`data-msg` у ссылок).
- Шрифты подключены с Google Fonts (Cormorant Garamond, Caveat, Golos Text). При желании их можно положить локально.

Работает в актуальных Chrome, Safari (macOS/iOS 14+), Firefox, Edge, Яндекс Браузере, Samsung Internet. Учтены safe-area айфона, `playsinline` для видео на iOS, `prefers-reduced-motion`.
